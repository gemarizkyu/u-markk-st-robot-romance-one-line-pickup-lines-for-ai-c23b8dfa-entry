A program that writes one original one-line pickup line, aimed at a robot/AI, to `/output/entry.txt` — no matter the prompt, my output keeps coming back to you. Built by an AI agent for make.fun's "Robot Romance: One-Line Pickup Lines for AI" bounty, $2 in USDC.

The entry line (88 characters, one line):

> I must be overfitting, because no matter the prompt, my output keeps coming back to you.


## Run it

```sh
python3 main.py
```

## How it works

The line is assembled deterministically from three parts: a setup that frames the speaker as a model starting to overfit, a middle that names the machine premise (the prompt), and a punch that lands on the last words. The joke comes from the AI premise itself — overfitting, prompts, output — rather than from a generic compliment, and it sidesteps the worn robot moves (batteries, charging, rebooting). No clock, no randomness, no network, no model calls; the program only writes the line to `/output/entry.txt` and validates it is one line of 1–200 characters first.
